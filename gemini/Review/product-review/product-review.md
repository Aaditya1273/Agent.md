# Purpose

This document defines the Product Review methodology.

Product review evaluates whether a feature delivers meaningful value to users and the business.

A technically correct implementation can still be a poor product.

The objective is to verify that every feature solves the correct problem, creates measurable value, aligns with business goals, and provides an excellent user experience.

Engineering builds software.

Product thinking builds successful software.

# Definition of Done

Product review is complete when

- The feature solves a validated user problem.
- The value proposition is immediately clear.
- The user journey is intuitive and efficient.
- Business objectives are supported.
- Success metrics are defined.
- Risks have been evaluated.
- The feature improves the overall product.
- Users can discover, understand, and successfully use it.
- The implementation supports future growth.
- The product delivers meaningful, measurable value to both users and the business.

A successful product is not defined by the number of features it contains.

It is defined by how effectively it solves important problems for the people who use it.
