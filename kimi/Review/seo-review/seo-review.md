# Purpose

This document defines the SEO Review methodology for modern web applications.

SEO is not about manipulating search engines.

SEO is the engineering discipline of making content discoverable, understandable, accessible, trustworthy, and valuable for both users and search engines.

The objective is to maximize organic visibility while preserving excellent user experience, technical quality, and content integrity.

Search engines reward products that genuinely help users.

# Primary Objective

Every SEO review should answer one question.

"If this page were the best answer to a user's question, would search engines clearly understand that?"

If the answer is uncertain,

the page requires improvement.

# Definition of Done

SEO review is complete when

- The page fully satisfies user search intent.
- Technical SEO follows modern best practices.
- Content demonstrates expertise, authority, and trust.
- Metadata accurately represents the page.
- Structured data is implemented correctly.
- Internal linking strengthens site architecture.
- Images and media are optimized.
- Core Web Vitals support an excellent user experience.
- Search engines can efficiently crawl, understand, and index the page.
- The page provides enough value to deserve long-term visibility in search results.

Exceptional SEO is not achieved by optimizing for search engines.

It is achieved by creating the most useful, trustworthy, technically excellent, and discoverable experience for the people performing the search.
